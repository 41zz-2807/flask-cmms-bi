3. Konfigurasi Email (SMTP)

Setting server SMTP untuk pengiriman email (notifikasi). Password tersimpan aman dan tidak ditampilkan; kosongkan kolom password bila tidak ingin mengubahnya.

Uji Pengiriman Email
